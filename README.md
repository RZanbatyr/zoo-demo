# Демо-сайт зоомагазина ZOO ДҮКЕН (шаблон для показа клиентам)

Витрина с корзиной без бэкенда: покупатель собирает корзину на сайте, а кнопка
«Заказать в WhatsApp» открывает WhatsApp магазина с готовым списком товаров,
суммой и адресом доставки. Оплата при получении (Kaspi / наличные).

Магазин вымышленный (Атырау), товары и цены условные, картинки сгенерированы
(`../gen/gen_img.py`, Gemini 3.1 Flash Image, упаковки без брендов).
Два языка: RU и KZ. Все контакты ведут на AR Marketing.

## Запуск

```
npm install        - один раз
node dev.cjs       - локально, http://localhost:5179
npm run build      - собрать в dist/ (это и заливаем)
```

## Что менять под реального клиента

`src/content.ts`: название, адрес, телефон и WhatsApp (`shopBase`), тексты,
категории (`categories`), товары (`P` + `NAMES` для двух языков), доставка и оплата.
Картинки товаров и магазина: `public/img/`.

Корзина хранится в браузере покупателя (localStorage), сервер не нужен.
Текст заказа для WhatsApp собирается в `CartDrawer` (App.tsx).
